Privacy policy

Wee’s Personal rclone

Effective date: November 12, 2026

1. Operator and scope

Wee’s Personal rclone is operated by Wee (weeix) exclusively for the operator’s own Google Drive file transfers, syncing, and backups using rclone. It is not a service offered to other users. This policy covers the personal OAuth client and this informational website.

2. Information accessed

When the operator authorizes the application through Google, rclone receives OAuth credentials that permit the access granted by the operator. Depending on the configured scopes and operations, rclone may access Drive file contents and metadata, including file names, identifiers, folder structures, sizes, and modification times. It may also export Google Workspace documents.

Permissions may allow listing, reading, downloading, uploading, creating, modifying, and deleting files. Actual access depends on the scopes granted and the commands the operator runs. Google handles account authentication; this website does not ask for or receive a Google password.

3. How information is used

Google user data is used only to carry out file-management, synchronization, and backup operations requested or configured by the operator. Data is not used for advertising, profiling, sale, or training machine-learning or AI models.

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

4. Storage and security

OAuth tokens are stored in the operator’s rclone configuration on the devices or systems where rclone is installed. Files and backups may be stored on local disks or destinations selected by the operator. Logs may contain file names, paths, or operational metadata, depending on the logging settings.

The operator is responsible for access controls, protecting configuration files and backups, and choosing appropriate encryption and logging settings. This website and its public source repository do not store OAuth credentials or Drive files. No security measure can guarantee absolute protection.

5. Sharing and transfers

The operator does not sell Google user data or share it for advertising. Transfers occur only as needed to perform the operator’s configured operations, such as copying a file to a selected storage provider. Those providers process transferred data under their own terms and privacy policies. The application does not make Drive data publicly available by default.

6. Retention, deletion, and revocation

Local files, backups, logs, and configuration remain until the operator deletes them or a configured retention policy removes them. To stop future access, remove the application’s authorization from Google Account connections and remove the relevant credentials from the rclone configuration.

Revoking access does not delete files or backups already transferred. The operator must delete those separately from each destination, along with any retained logs or credentials as appropriate.

7. Website hosting

This is a static website hosted on GitHub Pages. It contains no application-added analytics, tracking scripts, cookies, forms, or sign-in features. GitHub may process technical request information when serving the site under the GitHub Privacy Statement. Following external links is subject to the destination’s policies.

8. Contact and changes

Privacy questions or deletion-related inquiries can be submitted through the repository’s GitHub Issues page. Issues are public; never include secrets, OAuth tokens, private files, or sensitive personal information. If this policy changes, the updated policy and effective date will be published here.
